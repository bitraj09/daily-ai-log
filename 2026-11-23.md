# 23 Nov 2026 — LangGraph Agents in One Minute

LangGraph turns an LLM agent from a single prompt into a stateful graph: nodes do the work (call tools, reason, write), edges decide what happens next, and shared state carries memory between steps. That makes loops, retries and human-in-the-loop checks explicit instead of hidden inside one long chain.

Typical pattern: planner node -> tool node -> checker node -> if the result is good, finish; if not, loop back to the planner with the error in state.

```python
# Minimal LangGraph-style agent loop (no framework needed to see the idea)
state = {"task": "Summarise this dental report", "tries": 0, "done": False}

def plan(s):
    s["tries"] += 1
    return {**s, "draft": f"Draft v{s['tries']}: landmarks detected, report ready."}

def check(s):
    return {**s, "done": "landmarks" in s["draft"]}

while not state["done"] and state["tries"] < 3:
    state = check(plan(state))

print(state["draft"], "| tries:", state["tries"])
```

Takeaway: when an agent needs retries, branching or approval, model it as a graph with state — not as a longer prompt.
