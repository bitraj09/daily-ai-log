# 2026-11-22 — YOLO / Object Detection

## Concept

YOLO (You Only Look Once) treats object detection as a single regression problem: one forward pass over the image predicts bounding boxes and class probabilities for the whole scene at once. The image is divided into a grid, and each cell predicts boxes for objects whose centre falls inside it, along with a confidence score. Because detection happens in one pass, YOLO runs in real time — which is why it is the go-to choice for live video, robotics, and medical-imaging pipelines like dental X-ray landmark detection. Modern versions (v8, v11) are anchor-free, use stronger backbones, and export cleanly to ONNX / TensorRT for edge deployment.

## Snippet

```python
from ultralytics import YOLO

# Load a pretrained YOLOv8 nano model (fast, CPU-friendly)
model = YOLO("yolov8n.pt")

# Run detection on one image; conf filters weak predictions
results = model.predict("street.jpg", conf=0.5, save=True)

for r in results:
    for box in r.boxes:
        x1, y1, x2, y2 = box.xyxy[0].tolist()
        label = r.names[int(box.cls[0])]
        print(f"{label}: {box.conf[0]:.2f} at ({x1:.0f}, {y1:.0f}, {x2:.0f}, {y2:.0f})")
```

## Takeaway

Detection speed comes from predicting everything in one pass — no separate region-proposal step. For real-time use, start with a nano model, tune the confidence threshold, and only scale up the model size when accuracy actually demands it.
