# Day 4 — LoRA / QLoRA Fine-Tuning (2026-11-24)

## Concept
LoRA (Low-Rank Adaptation) fine-tunes a large model by freezing its original weights and training only two small low-rank matrices (A and B) that are added to selected layers. With rank r = 8–16, the trainable parameters drop to under 1% of the model, so fine-tuning fits on a single consumer GPU. QLoRA goes further: the base model is loaded in 4-bit (NF4) quantisation, cutting memory by roughly 75%, while the LoRA adapters still train in 16-bit — a 7B model can be fine-tuned in about 6 GB of VRAM. The adapters are merged back into the base weights (or kept separate) at inference time.

## Snippet
```python
from peft import LoraConfig, get_peft_model, prepare_model_for_kbit_training
from transformers import AutoModelForCausalLM, BitsAndBytesConfig
import torch

bnb = BitsAndBytesConfig(load_in_4bit=True, bnb_4bit_quant_type="nf4",
                         bnb_4bit_compute_dtype=torch.bfloat16)
model = AutoModelForCausalLM.from_pretrained(
    "meta-llama/Llama-3.2-1B", quantization_config=bnb, device_map="auto")
model = prepare_model_for_kbit_training(model)

peft_cfg = LoraConfig(r=16, lora_alpha=32, lora_dropout=0.05,
                      target_modules=["q_proj", "v_proj"],
                      task_type="CAUSAL_LM")
model = get_peft_model(model, peft_cfg)
model.print_trainable_parameters()  # ~0.5% of params trainable
```

## Takeaway
Freeze the base model and train only low-rank adapters — LoRA gives near-full fine-tuning quality at a fraction of the memory and cost, and QLoRA's 4-bit base makes even 7B+ models fine-tunable on one GPU.
