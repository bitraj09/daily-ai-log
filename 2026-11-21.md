# 21 Nov 2026 — RAG in one minute

Retrieval-Augmented Generation (RAG) = retrieve relevant chunks first, then let the LLM answer only from those chunks. This cuts hallucinations and keeps answers grounded in your own data.

Pipeline: docs -> chunk (500-1000 chars, overlap 100) -> embed (e.g. text-embedding-3-small) -> vector store -> top-k retrieval (k=3-5) -> prompt with context -> LLM answer with citations.

```python
# Minimal RAG retrieval sketch
from sklearn.feature_extraction.text import TfidfVectorizer
from sklearn.metrics.pairwise import cosine_similarity

docs = ["Dental AI detects landmarks with YOLO.", "RAG grounds LLM answers in retrieved docs."]
query = "How does Dental AI detect landmarks?"
vec = TfidfVectorizer().fit_transform(docs + [query])
scores = cosine_similarity(vec[-1], vec[:-1])[0]
print(docs[int(scores.argmax())])
```

Takeaway: retrieval quality matters more than model size for grounded answers.
